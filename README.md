# 农子财务管理系统

面向种子（品种）经营企业的本地业务管理系统，覆盖 **库存、财务、销售、客户、员工** 五大领域，
并带三级数据权限（L1 高管层 / L2 经理层 / L3 员工层）。

按需求书《农子财务系统需求文档.md》实现，采用 TDD 方式开发。

---

## 快速开始

### Windows 用户

双击 **`农子财务管理系统.lnk`**（带图标的快捷方式）即可 —— 它是
`农子财务管理系统.bat` 的快捷方式，两者都能启动，区别只在于图标。

程序会自动：

1. 在本机启动后端服务（默认 `http://127.0.0.1:8787`，端口被占用则自动顺延）
2. 首次运行时自动建库、建表、写入基础数据
3. 自动打开浏览器进入登录页

首次启动会在控制台打印默认管理员账号与随机初始密码，请登录后尽快修改。

> **关于图标**：Windows 的 `.bat` 文件本身无法携带自定义图标（资源管理器只会显示通用批处理图标）。
> 想看到图标，请使用 `.lnk` 快捷方式 —— 可以把它复制到桌面或固定到任务栏。
> 注意快捷方式记录的是绝对路径，**移动文件夹后需要重新运行 `tools\make-shortcut.ps1` 重建**。

**卸载**：删除整个目录即可，所有数据都在 `data/` 子目录内。

### 命令行

```bash
npm start        # 启动系统
npm test         # 运行全部测试（约 2 秒）
```

无需 `npm install` —— 默认使用 Node 内置的 SQLite，零第三方依赖。

## 数据库

默认使用 **内嵌 SQLite**，开箱即用。如需切换数据库，在界面上进入「系统 → 数据库配置」，
或直接编辑根目录的 `config.json`，重启后生效。

| 数据库 | 配置 `dialect` | 需安装驱动 |
| --- | --- | --- |
| SQLite（默认） | `sqlite` | 无需安装 |
| MySQL / MariaDB | `mysql` | `npm install mysql2` |
| PostgreSQL | `pg` | `npm install pg` |
| SQL Server | `mssql` | `npm install mssql` |

切换数据库**不需要改动任何业务代码**：业务 SQL 统一用 `?` 占位符书写，由方言层翻译成
`$1`（PostgreSQL）或 `@p1`（SQL Server）；建表语句用 `{{TEXT}}` / `{{MONEY}}` 等逻辑类型标记，
由方言层展开为各库的原生类型。

### 配置示例

```json
{
  "server": { "host": "127.0.0.1", "port": 8787 },
  "database": {
    "dialect": "mysql",
    "host": "192.168.1.10",
    "port": 3306,
    "database": "nongzi",
    "user": "nongzi",
    "password": "******"
  }
}
```

### 测试

```bash
npm test              # 全部
npm run test:domain   # 纯逻辑（最快，TDD 内循环用这个）
npm run test:db
npm run test:service
npm run test:http     # 端到端，含权限隔离
npm run coverage      # 带覆盖率
```

> **注意**：请始终使用 `npm test` 或显式 glob。直接运行 `node --test` 会按 Node 默认规则
> 扫描测试目录，可能把 `tests/helpers/` 下的夹具文件也当作测试执行。

测试全部使用内存 SQLite（`tests/helpers/db.js`）。这不仅是速度考虑：本项目的开发目录
位于 WSL 的 9p 挂载盘上，文件级锁在该文件系统上不可靠，落盘数据库在测试中会出现偶发锁定失败。

### TDD 约定

每个功能都遵循 **RED（先写失败的测试）→ GREEN（最小实现）→ REFACTOR**。
新增一条需求书里的查询时，先在对应的 `tests/service/*.test.js` 里写出断言，
再实现。权限相关的断言尤其重要——需求书 2.2 要求权限贯穿所有模块，
因此每个读接口都必须有对应的范围隔离测试。

## 安全说明

本系统虽为单机程序，仍按联网应用的标准处理了几处关键风险：

- **只监听 `127.0.0.1`**，不绑定 `0.0.0.0`，局域网内其他机器无法访问
- **校验请求来源**，防止浏览器中的恶意页面通过 DNS 重绑定访问本机服务
- **密码用 scrypt 加随机盐**存储，不落明文
- **登录失败提示统一**，「工号不存在」与「密码错误」返回相同文案，避免工号被枚举
- **数据范围一律由服务端会话计算**，不接受前端传参放宽
- **身份证与家庭住址对非高管脱敏**
- **前端不使用 `innerHTML` 渲染业务数据**，避免自由文本字段造成存储型 XSS

## 常见问题

**双击 `农子财务管理系统.bat` 后窗口一闪而过？**
正常情况下窗口会保持打开并显示访问地址（关掉窗口即停止服务）。若一闪而过，
说明 Node 没找到或启动即失败。请在**命令行**里手动执行一次以看到完整报错：

```bat
cd /d E:\claude-demo\农子财务系统需求
农子财务管理系统.bat
```

**访问地址不是 8787？**
若 8787 端口已被其它程序占用，程序会**自动顺延**到 8788、8789…… 这是正常的。
浏览器打开的始终是实际端口，无需手工改地址。想固定端口就编辑 `config.json`。

**不想自动打开浏览器？**
设置环境变量 `NZ_NO_BROWSER=1` 再启动。部署为后台服务时也用这个。

**忘记管理员密码？**
删除 `data\nongzi.db` 会清空全部数据并重新生成管理员账号——**仅在确认可以丢弃数据时使用**。
